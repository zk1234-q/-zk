# 01 PRD

## 产品定位

Expense Bill Analyzer 是一个个人消费账单分析工具。

用户上传 iCost 导出的 Excel 或 CSV 账单后，系统自动解析消费数据，并生成按月份、一级分类、二级分类统计的分析表格。

第一阶段优先做本地单用户版本，不做登录、不做多用户、不做云端同步、不做复杂权限。

## 核心用户

- 使用 iCost 记录个人消费的用户
- 想按月份查看消费结构的用户
- 想知道钱主要花在哪些一级分类和二级分类上的用户
- 不需要复杂记账系统，只需要本地分析账单的用户

## 核心目标

第一版需要支持：

1. 上传 iCost 导出的 Excel 或 CSV 文件
2. 识别消费日期、金额、一级分类、二级分类等字段
3. 按月份汇总收入、支出、结余和结余率
4. 展示一级分类支出占比表
5. 展示二级分类支出占比表
6. 展示一级分类 + 二级分类综合表
7. 点击金额字段查看对应消费明细
8. 确保所有金额合计和原始账单能对得上

## 核心使用流程

1. 用户进入首页
2. 上传 iCost 导出的 Excel 或 CSV 文件
3. 系统解析文件并展示数据预览
4. 用户确认数据字段识别结果
5. 系统生成月度汇总和分类统计表
6. 用户切换月份查看不同月份数据
7. 用户点击金额字段查看对应明细

## 上传账单流程

- 支持 Excel 和 CSV 文件
- 上传后先做基础字段识别
- 需要识别消费日期、金额、类型、一级分类、二级分类、商户、备注、支付方式
- 如果字段缺失，需要在预览阶段明确提示
- 如果存在无法解析的行，需要单独标记，不直接混入统计

## 表格展示流程

系统需要生成以下表格：

1. 月度汇总表
2. 一级分类支出占比表
3. 二级分类支出占比表
4. 一级分类 + 二级分类综合表

表格需要支持：

- 月份切换
- 按金额排序
- 金额字段可点击
- 百分比字段清晰展示

## 点击金额查看明细流程

点击不同金额时，弹框展示不同范围的账单明细：

- 点击总支出：展示该月份所有支出明细
- 点击一级金额：展示该月份、该一级分类下的所有支出明细
- 点击二级金额：展示该月份、该一级分类、该二级分类下的所有支出明细

弹框底部需要展示：

- 明细笔数
- 明细合计金额

明细合计金额必须和被点击的金额一致。

## 异常数据处理规则

- 默认只统计类型为“支出”的记录
- 不把“借入”“转账”“退款”“收入”算入消费支出
- 负数、退款、借入、转账等特殊记录需要单独列出处理规则
- 不确定类型的数据需要在预览或异常列表中提示
- 月份按消费日期归属
- 非完整月份需要标注“非完整月，仅参考”

## 默认业务口径

- 默认月收入为 9000 元
- 月份按消费日期计算
- 支出统计只包含消费支出
- 第一版先做本地分析，不做账号体系

## 未来可扩展功能

- 支持自定义月收入
- 支持多账本
- 支持预算设置
- 支持图表分析
- 支持后端数据库
- 支持历史数据保存
- 支持多用户登录
- 支持更多账单来源

## 第一版验收标准

1. 可以上传 iCost 导出的 Excel
2. 可以识别消费日期、金额、一级分类、二级分类
3. 可以按月份汇总
4. 可以展示一级分类表
5. 可以展示二级分类表
6. 可以展示一级 + 二级综合表
7. 点击一级金额可以查看对应明细
8. 点击二级金额可以查看对应明细
9. 所有金额合计能对得上原始账单
10. 所有占比公式正确
11. 页面能在本地正常运行
