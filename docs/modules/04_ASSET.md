# Module: Asset Overview

## 模块状态

已实现本地版，版本：V2.5。

## 模块目标

资产总览用于记录每次资产负债盘点。

用户希望可以自由维护资产负债档案，再在资产总览里新增记录、选择档案字段、填写金额。

## 核心概念

### 资产负债档案

档案用于维护可选字段，不直接表示某次盘点金额。

示例：

- 支付宝
- 微信
- 基金
- 补贴
- 公积金
- 理财通
- 房贷
- 车贷
- 信用卡
- 花呗
- 借呗

字段：

| 字段 | 说明 |
| --- | --- |
| id | 唯一 ID |
| name | 档案名称 |
| type | `asset` 或 `liability` |
| remark | 备注 |
| enabled | 是否启用 |
| createdAt | 创建时间 |
| updatedAt | 更新时间 |

已经被历史记录使用的档案不建议物理删除，只做停用。

### 资产总览记录

按钮名称：`新增`。

新增时用户选择日期，并逐行选择资产负债档案、填写金额。

字段：

| 字段 | 说明 |
| --- | --- |
| id | 唯一 ID |
| snapshotDate | 盘点日期 |
| items | 盘点明细 |
| totalAsset | 总资产，计算字段 |
| totalLiability | 总负债，计算字段 |
| netAsset | 净资产，计算字段 |
| remark | 备注 |
| createdAt | 创建时间 |
| updatedAt | 更新时间 |

明细字段：

| 字段 | 说明 |
| --- | --- |
| id | 唯一 ID |
| accountId | 资产负债档案 ID |
| accountName | 保存当时的档案名称快照 |
| accountType | 保存当时的资产/负债类型快照 |
| amount | 金额 |
| remark | 备注 |

## 计算公式

```text
总资产 = 所有 asset 明细金额合计
总负债 = 所有 liability 明细金额合计
净资产 = 总资产 - 总负债
```

## 页面建议

资产总览页面包含：

- 顶部汇总卡：总资产、总负债、净资产、最近盘点日期。
- 新增按钮。
- 资产负债档案管理入口。
- 历史盘点记录列表。
- 盘点详情弹窗或抽屉。

## V2.5.1 资产看板优化设计

状态：已实现。

本次优化目标是把资产总览从“档案和历史表格页面”调整为“当前资产看板”。

核心口径：

- 主页只展示最新一次盘点记录。
- 主页核心回答：现在总资产是多少、总负债是多少、净资产是多少、钱分别在哪些明细里。
- 资产负债档案只是字段配置，不再作为主页大块内容展示。
- 历史记录只是追溯入口，不再作为主页大块内容展示。

### 主页布局

资产总览主页包含：

- 顶部核心指标：净资产、总资产、总负债、最新盘点日期。
- 最新资产明细：按最新盘点记录中的资产类明细展示。
- 最新负债明细：按最新盘点记录中的负债类明细展示。
- 操作入口：更新资产盘点、查看历史记录、管理档案。

历史记录和资产负债档案通过弹窗或抽屉打开。

### 明细排序

最新盘点明细支持用户自由排序。

第一版使用“上移 / 下移”实现，不引入拖拽库。

排序结果直接保存为当前资产盘点记录的 `items` 数组顺序。

新增下一次资产盘点时，默认沿用最近一次盘点的明细顺序。

### 参与统计

每条资产盘点明细增加“参与统计”开关。

- 资产类明细开启后计入总资产。
- 负债类明细开启后计入总负债。
- 关闭后仍展示在明细中，但不参与顶部总资产、总负债、净资产计算。
- 旧数据没有该字段时，默认视为参与统计。

字段建议：

| 字段 | 说明 |
| --- | --- |
| includedInTotal | 是否参与统计，默认 `true` |

### 资产分组

资产负债档案增加分组字段，用于让明细更清晰。

字段建议：

| 字段 | 说明 |
| --- | --- |
| groupName | 分组名称，例如现金、投资、长期资产、短期负债、长期负债 |

分组是展示和筛选口径，不改变资产 / 负债本身类型。

V2.5.1 不做资产健康评分、不做可动用资产、不做短期负债独立指标、不做统计口径快捷按钮。

## V2.5.2 排序和历史统计优化设计

状态：已实现。

### 明细排序交互

资产看板默认不显示排序控件。

主页右上角提供“排序”按钮：

- 点击“排序”后进入排序模式。
- 明细行最后显示三条横线拖拽手柄。
- 用户通过拖动手柄调整明细顺序。
- 点击“完成排序”退出排序模式。

排序结果保存到最新盘点记录的 `items` 数组顺序。

### 历史资产记录

历史资产记录用于对比不同日期、月份、年份的资产状态。

历史弹窗提供统计维度切换：

- 按天
- 按月
- 按年

默认按天显示。

### 按天统计

- 默认选择最新年份的最新月份。
- 只显示所选月份内的资产盘点记录。
- 每行显示：日期、总资产、总负债、净资产、备注。
- 点击净资产金额，查看当天盘点明细。

### 按月统计

- 默认选择最新年份。
- 每个月取该月最后一条盘点记录作为月结数据。
- 每行显示：月份、总资产、总负债、净资产、来源日期、备注。
- 点击净资产金额，查看该月结算来源记录的盘点明细。

### 按年统计

- 每年取当年最后一条盘点记录作为年结数据。
- 每行显示：年份、总资产、总负债、净资产、来源日期、备注。
- 点击净资产金额，查看该年结算来源记录的盘点明细。

V2.5 不自动读取支付宝、微信、银行数据。

V2.5 不自动联动预算和目标。
