# Module: Asset Overview

## 模块状态

已实现本地版，版本：V2.5。

## 模块目标

资产总览用于记录每次资产负债盘点。

用户希望可以自由维护资产负债档案，再在资产总览里新增记录、选择档案字段、填写金额。

## 核心概念

### 资产负债档案

档案用于维护可选字段，不直接表示某次盘点金额。

示例：

- 支付宝
- 微信
- 基金
- 补贴
- 公积金
- 理财通
- 房贷
- 车贷
- 信用卡
- 花呗
- 借呗

字段：

| 字段 | 说明 |
| --- | --- |
| id | 唯一 ID |
| name | 档案名称 |
| type | `asset` 或 `liability` |
| remark | 备注 |
| enabled | 是否启用 |
| createdAt | 创建时间 |
| updatedAt | 更新时间 |

已经被历史记录使用的档案不建议物理删除，只做停用。

### 资产总览记录

按钮名称：`新增`。

新增时用户选择日期，并逐行选择资产负债档案、填写金额。

字段：

| 字段 | 说明 |
| --- | --- |
| id | 唯一 ID |
| snapshotDate | 盘点日期 |
| items | 盘点明细 |
| totalAsset | 总资产，计算字段 |
| totalLiability | 总负债，计算字段 |
| netAsset | 净资产，计算字段 |
| remark | 备注 |
| createdAt | 创建时间 |
| updatedAt | 更新时间 |

明细字段：

| 字段 | 说明 |
| --- | --- |
| id | 唯一 ID |
| accountId | 资产负债档案 ID |
| accountName | 保存当时的档案名称快照 |
| accountType | 保存当时的资产/负债类型快照 |
| amount | 金额 |
| remark | 备注 |

## 计算公式

```text
总资产 = 所有 asset 明细金额合计
总负债 = 所有 liability 明细金额合计
净资产 = 总资产 - 总负债
```

## 页面建议

资产总览页面包含：

- 顶部汇总卡：总资产、总负债、净资产、最近盘点日期。
- 新增按钮。
- 资产负债档案管理入口。
- 历史盘点记录列表。
- 盘点详情弹窗或抽屉。

## 边界

V2.5 不做云端同步。

V2.5 不自动读取支付宝、微信、银行数据。

V2.5 不自动联动预算和目标。

## 实现状态

已实现：

- 资产负债档案。
- 档案启用 / 停用。
- 资产总览“新增”。
- 新增时可选择档案字段并填写金额。
- 新增时默认带出最近一次盘点金额。
- 历史记录。
- 编辑、复制新增、删除资产记录。
- 自动计算总资产、总负债、净资产。
- 本地备份导出 / 导入包含资产数据。
