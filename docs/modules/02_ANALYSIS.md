# Module: Monthly Analysis

## 模块目标

月度分析模块负责查看按月统计结果、分类统计、图表和消费明细。

## V2.1 调整

月度汇总表需要调整为长期使用友好的方式：

- 按账单月份倒序展示。
- 先按年份，再按月份。
- 默认展示最新年份。
- 每页显示 12 个月。
- 支持选择年份。

## 当前能力

- 月度汇总。
- 一级分类表。
- 二级分类表。
- 一级 + 二级综合表。
- 月度趋势图。
- 一级占比图。
- 二级排行图。
- 点击金额查看明细。
- 联动预算状态。

## 数据口径

月度汇总核心公式：

```text
月结余 = 月收入 - 月总支出
结余率 = 月结余 / 月收入
```

分类占比核心公式：

```text
一级分类占总支出 = 一级分类金额 / 当月总支出
二级分类占总支出 = 二级分类金额 / 当月总支出
二级分类占一级分类 = 二级分类金额 / 所属一级分类金额
```

## V2.1 验收标准

- 月度汇总默认最新年份。
- 月份从大到小排序，例如 `2026-12` 在 `2026-01` 前面。
- 每页 12 个月。
- 年份选择不会影响一级、二级分类对当前月份的分析。
- 当前月份选择仍然可用。

## 后续云端预留

月度分析应尽量按需读取数据：

- 当前月份账单。
- 当前年份月度摘要。
- 当前月份预算。

不要在云端版本一次性拉取所有账单明细。
