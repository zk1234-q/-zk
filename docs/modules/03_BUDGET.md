# Module: Budget Management

## 模块目标

预算管理模块负责：

- 总预算设置。
- 月度账单大类预算。
- 月度预算总览。
- 月度结算。
- 独立购物预算。

## 当前边界

账单大类预算联动账单。

独立购物预算不联动账单，只做手工维护。

## 当前能力

- 设置年支出总预算。
- 设置月攒钱预算。
- 设置月总支出预算。
- 按月维护大类预算。
- 从当月账单一级分类中选择预算大类。
- 自动计算已支出、剩余、使用率、状态。
- 复制月份预算。
- 维护独立购物预算表。

## V2.7 独立购物预算优化设计

### 目标

把当前“明细行自己维护预算”的独立购物预算，调整为更适合长期维护的三层结构：

```text
分类计划 -> 品类预算档案 -> 购物明细
```

示例：

- 分类计划：年度服装预算，总预算 6000 元。
- 品类预算档案：外套 1800 元、裤子 1000 元、鞋子 1200 元。
- 购物明细：羊毛大衣、牛仔裤、运动鞋等具体计划或已购买项目。

### 分类计划

分类计划用于把不同预算主题拆开，避免服装、电子设备等明细混在一起。

字段：

| 字段 | 说明 |
| --- | --- |
| 计划名称 | 例如年度服装预算、电子设备预算 |
| 总预算 | 当前分类计划的总预算 |
| 已占用预算 | 当前分类计划下所有品类占用金额合计 |
| 剩余预算 | 总预算 - 已占用预算 |
| 排序 | 控制页签显示顺序 |
| 备注 | 可选说明 |

页面表现：

- 分类计划以表格展示，选中某一行后，下方品类预算档案和购物明细联动显示该分类计划的数据。
- 顶部展示所有分类计划的总预算、已占用预算、剩余预算。
- 当前选中的分类计划行需要高亮。
- 单个分类计划超预算时，对应剩余预算标红。

### 品类预算档案

品类预算档案归属于某个分类计划，用于设置具体品类的预算上限。

字段：

| 字段 | 说明 |
| --- | --- |
| 分类计划 ID | 归属的分类计划 |
| 品类名称 | 例如外套、裤子、电脑、手机 |
| 品类预算 | 当前品类预算上限 |
| 计划金额合计 | 当前品类下明细计划金额合计 |
| 实际金额合计 | 当前品类下明细实际金额合计 |
| 占用金额 | 已购买用实际金额，未购买用计划金额 |
| 剩余预算 | 品类预算 - 占用金额 |
| 排序 | 控制品类显示顺序 |
| 备注 | 可选说明 |

页面表现：

- 品类预算档案单独显示，不再把品类剩余预算放到明细行。
- 当计划金额合计超过品类预算时，计划金额标红。
- 当实际金额合计超过品类预算时，实际金额标红。
- 当剩余预算小于 0 时，剩余预算标红。

### 购物明细

购物明细归属于某个分类计划，并选择该计划下的品类。

字段：

| 字段 | 说明 |
| --- | --- |
| 分类计划 ID | 归属的分类计划 |
| 品类 ID | 从品类预算档案中选择 |
| 具体项目 | 例如羊毛大衣、运动鞋 |
| 计划数量 | 手工填写 |
| 计划金额 | 手工填写 |
| 实际金额 | 手工填写 |
| 状态 | 计划中 / 已购买 / 暂缓 / 放弃 |
| 排序 | 控制明细显示顺序 |
| 备注 | 可选说明 |

字段删除：

- 不再维护单位。
- 不再维护实际单价。
- 不再在明细行展示品类剩余预算。
- 不再保留推荐方案和购买内容两个分散字段，统一用具体项目和备注承载。

选择品类时：

- 新增明细行先选择品类。
- 选择品类后可展示该品类预算作为参考信息。
- 明细行不复制保存品类预算金额，预算以品类档案为准实时计算。

### 预算计算口径

```text
品类计划金额合计 = 当前品类所有明细的计划金额合计
品类实际金额合计 = 当前品类所有明细的实际金额合计
```

占用金额按状态计算：

```text
已购买：使用实际金额
计划中：使用计划金额
暂缓：使用 0
放弃：使用 0
```

剩余预算：

```text
品类剩余预算 = 品类预算 - 品类占用金额
分类计划剩余预算 = 分类计划总预算 - 分类计划下所有品类占用金额合计
全部剩余预算 = 全部分类计划总预算 - 全部分类计划已占用预算
```

说明：

- 不采用“计划金额 + 实际金额”直接相加作为占用金额，避免同一件商品从计划转为已购买后重复占用预算。
- 计划金额合计和实际金额合计仍分别用于超预算提示。

### 排序交互

排序参考资产总览的拖动排序：

- 默认不显示拖拽手柄。
- 点击“排序”按钮后进入排序模式。
- 行首显示三横线拖拽手柄。
- 拖动调整顺序。
- 点击“保存排序”后写入本地数据。
- 点击“取消”放弃本次排序。
- 刷新页面后保持已保存顺序。

排序范围：

- 分类计划排序：控制页签顺序。
- 品类档案排序：控制当前分类计划下的品类顺序。
- 购物明细排序：控制当前分类计划下的明细顺序。

数据规则：

- 使用 `sortOrder` 字段保存顺序。
- 新增分类计划、品类、明细时默认排到当前范围最后。
- 排序不影响预算计算。

### 旧数据兼容

现有 `shoppingBudgetItems` 需要迁移到新结构：

- 旧 `categoryName` 迁移为品类名称。
- 旧 `budgetAmount` 迁移为明细计划金额。
- 旧 `actualUnitAmount * purchasedQuantity` 迁移为明细实际金额。
- 旧 `plannedQuantity` 继续保留为计划数量。
- 旧 `purchasedQuantity > 0` 的明细状态迁移为已购买，否则按旧状态映射。
- 如果旧数据没有分类计划，默认归入“默认购物预算”分类计划。
- 品类预算初始值可取旧同名品类明细计划金额合计，用户后续可自行调整。

## 后续优化原则

预算管理不要和资产总览混在一个页面。

预算回答的是：

```text
这个月计划花多少，实际花了多少，是否超支？
```

资产总览回答的是：

```text
我现在一共有多少钱，欠多少钱，净资产是多少？
```

目标管理回答的是：

```text
我离目标还差多少，每月还需要存多少？
```

## 验收标准

- 不影响账单管理和月度分析的已有数据。
- 预算计算字段从账单和预算实时计算，不把计算结果作为最终事实。
- 金额展示保留 2 位小数。
- 百分比展示保留 1 位小数。
- 独立购物预算支持分类计划、品类预算档案、购物明细三层管理。
- 分类计划、品类档案、购物明细均支持拖动排序并保存。
- 品类预算超出时按计划金额、实际金额、剩余预算分别标红。
- 旧购物预算数据迁移后仍可查看和继续编辑。
