# Module: Settings

## 模块目标

设置模块负责管理全局设置和本地数据备份。

## 当前能力

- 默认月收入设置。
- 本地数据导出。
- 本地数据导入。

## V2.1 调整

系统名称改为：

```text
账单管理分析系统
```

推荐副标题：

```text
账单分析 · 资产盘点 · 目标管理
```

## 本地备份

当前导出格式为 JSON。

导出内容包括：

- 用户设置。
- 总预算设置。
- 月度大类预算。
- 购物预算明细。
- 已保存账单。
- 资产负债档案。
- 资产盘点记录。
- 目标档案。

## 后续扩展

备份文件已扩展 `goals` 字段。

每次扩展备份结构必须提升 `schemaVersion`。

## 云端预留

设置模块以后应区分：

- 本地设置。
- 用户云端设置。
- 数据备份/迁移。

V3.0 云端版本需要提供“本地数据迁移到云端”的入口，而不是只做 JSON 导入导出。
