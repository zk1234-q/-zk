## 工作流页面

以下页面不作为常驻导航：

- 上传账单
- 数据预览

它们属于账单管理流程。

```text
账单管理 -> 上传账单 -> 数据预览 -> 保存 -> 月度分析
```

## V2.1 界面优化要求

- 修复顶部标题在浏览器窗口较窄时被遮挡的问题。
- 左上角品牌图标不再使用单字“账”作为唯一视觉。
- 视觉风格保持工具型、数据型，不做营销页风格。
- 主要操作按钮保留明确文字。
- 表格区域优先保证可读性和核对效率。

## 月度分析筛选

月度汇总表需要：

- 默认最新年份。
- 支持年份切换。
- 月份倒序。
- 每页 12 个月。
