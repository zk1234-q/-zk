# 03 UI Flow

## 页面设计目标

页面需要让非专业用户也能顺利完成账单上传、数据确认、本地保存历史月份、按月份查看分析结果、点击金额查看明细。

第一版优先保证流程清晰、表格准确，不追求复杂视觉效果。

## 页面列表

1. 首页 / 上传页
2. 账单管理页
3. 数据预览页
4. 月度分析页
5. 图表分析区
6. 一级分类表
7. 二级分类表
8. 一级 + 二级综合表
9. 异常数据列表
10. 消费明细弹框

## 首页 / 上传页

### 目标

让用户上传 iCost 导出的 Excel 或 CSV 文件。

### 核心内容

- 文件上传入口
- 支持文件格式提示
- 简单说明当前版本只做本地解析
- 已保存月份入口
- 上传失败或格式错误提示

### 用户操作

1. 点击上传按钮
2. 选择 Excel 或 CSV 文件
3. 系统进入解析流程
4. 解析成功后跳转到数据预览页

## 账单管理页

### 目标

让用户按月份管理已经上传并保存在本地浏览器中的账单。

### 核心内容

- 已保存月份列表
- 每个月的上传文件名
- 上传时间
- 支出笔数
- 月总支出
- 异常记录数
- 上传新账单入口

### 用户操作

1. 查看已保存月份
2. 点击某个月份进入月度分析页
3. 上传新的月份账单
4. 如果重复上传同一个月份，系统提示是否覆盖旧数据

## 数据预览页

### 目标

让用户确认系统是否正确识别账单字段。

### 核心内容

- 原始数据前若干行预览
- 标准化后的字段预览
- 异常数据列表
- 统计范围说明
- 保存到本地按钮

### 用户操作

1. 查看字段识别结果
2. 查看异常数据
3. 确认统计范围
4. 点击保存，把该月份账单保存到本地
5. 保存成功后进入月度分析页

## 月度分析页

### 目标

展示每个月的收入、支出、结余、结余率。

### 核心字段

- 月份
- 月收入
- 月总支出
- 月结余
- 结余率
- 支出笔数
- 异常记录数
- 备注

### 交互

- 月份可切换
- 点击月总支出，打开该月份全部支出明细弹框
- 非完整月份显示“非完整月，仅参考”

## 图表分析区

### 目标

用图表辅助用户快速理解消费结构，但金额核对仍以表格为准。

### 图表

1. 月度总支出趋势图
2. 一级分类支出占比图
3. 二级分类支出排行图

### 交互

- 月度总支出趋势图展示所有已保存月份
- 一级分类支出占比图跟随当前月份变化
- 二级分类支出排行图跟随当前月份变化
- 图表为空时提示用户先上传账单

## 异常数据列表

### 目标

明确告诉用户哪些记录没有参与统计，以及没有参与统计的原因。

### 字段

1. 原始行号
2. 异常原因
3. 原始日期
4. 原始类型
5. 原始金额
6. 原始一级分类
7. 原始二级分类
8. 原始备注

### 交互

- 数据预览页展示本次上传文件的异常数据
- 月度分析页展示当前月份保存后的异常数据数量
- 异常数据默认不参与支出统计

## 一级分类表

### 字段

1. 一级分类
2. 一级金额
3. 一级占总支出
4. 一级占收入
5. 笔数
6. 备注

### 交互

- 支持按一级金额排序
- 点击一级金额，弹框展示该月份、该一级分类下的所有消费明细

## 二级分类表

### 字段

1. 一级分类
2. 二级分类
3. 二级金额
4. 二级占总支出
5. 二级占收入
6. 笔数
7. 备注

### 交互

- 支持按二级金额排序
- 点击二级金额，弹框展示该月份、该一级分类、该二级分类下的所有消费明细

## 一级 + 二级综合表

### 字段顺序

1. 一级分类
2. 二级分类
3. 一级金额
4. 一级占总支出
5. 二级金额
6. 二级占总支出
7. 二级占一级
8. 一级占收入
9. 二级占收入
10. 二级笔数

### 交互

- 支持按一级金额排序
- 支持按二级金额排序
- 点击一级金额，展示该一级分类明细
- 点击二级金额，展示该二级分类明细

## 消费明细弹框

### 触发方式

- 点击月总支出
- 点击一级金额
- 点击二级金额

### 标题格式

- `2026-05 汽车消费明细`
- `2026-05 汽车-加油消费明细`
- `2026-05 全部支出明细`

### 表格字段

1. 日期
2. 一级分类
3. 二级分类
4. 金额
5. 商户
6. 支付方式
7. 备注

### 底部汇总

- 明细笔数
- 明细合计金额

明细合计金额必须和被点击的金额一致。

## 全局交互规则

- 表格需要支持月份切换
- 表格需要支持按金额排序
- 金额字段需要明显可点击
- 异常数据不能悄悄混入统计
- 已保存月份需要从本地读取
- 同月份重复上传需要二次确认
- 空数据状态需要提示用户重新上传或检查文件

# 第二版页面与交互设计：本地增强版（待确认）

## 第二版页面设计目标

第二版需要在第一版账单分析基础上，增加预算管理和本地数据迁移能力。

设计目标：

- 账单大类预算和独立购物预算分开，不混在一张表里。
- 账单大类预算按月份联动账单分析。
- 独立购物预算只做手工维护，不联动账单。
- 设置页提供默认月收入、本地数据导出和导入。
- 重复月份账单保存前给出清楚的覆盖确认。

## 第二版页面列表

在第一版页面基础上，新增或调整以下页面：

1. 设置页
2. 预算管理页
3. 月度预算总览区
4. 月度大类预算表
5. 月度结算视图
6. 独立购物预算表
7. 重复月份覆盖确认弹窗
8. 本地数据导入确认弹窗
9. 消费明细弹框预算信息区

## 全局导航调整

第二版建议顶部导航包含：

1. 上传账单
2. 账单管理
3. 月度分析
4. 预算管理
5. 设置

当前页面需要有明确选中状态。

## 设置页

### 目标

设置页用于管理全局设置和本地数据迁移。

### 核心区域

1. 默认月收入设置
2. 本地数据导出
3. 本地数据导入
4. 本地保存说明

### 默认月收入设置

字段：

- 默认月收入
- 货币单位：固定显示人民币
- 最后保存时间

交互：

1. 用户输入默认月收入
2. 点击保存
3. 页面提示“默认月收入已保存”
4. 月度分析页重新读取该设置

校验：

- 默认月收入不能为空
- 默认月收入不能小于 0
- 输入非法数字时提示用户修改

### 本地数据导出

交互：

1. 用户点击“导出本地数据”
2. 系统生成 JSON 备份文件
3. 浏览器下载文件
4. 页面提示“导出完成”

页面说明需要明确：

- 导出文件包含默认月收入、预算数据和已保存账单
- 换电脑时，可以在新电脑导入该文件
- 导出文件请用户自己保存好

### 本地数据导入

交互：

1. 用户点击“导入本地数据”
2. 选择 JSON 备份文件
3. 系统校验文件格式
4. 校验通过后展示导入确认弹窗
5. 用户确认后执行整包覆盖
6. 导入成功后刷新本地数据

如果文件格式错误：

- 不覆盖当前数据
- 显示错误提示

### 本地数据导入确认弹窗

弹窗内容需要明确告诉用户：

- 导入会覆盖当前浏览器里的本地数据
- 覆盖内容包括设置、预算、已保存账单
- 如果当前数据没有导出备份，覆盖后无法恢复

按钮：

- 确认导入
- 取消

## 预算管理页

### 目标

预算管理页用于管理账单大类预算和独立购物预算。

### 页面结构

预算管理页建议分为三个区域：

1. 总预算设置区
2. 月度账单大类预算区
3. 独立购物预算区

### 总预算设置区

字段：

- 年支出总预算
- 月攒钱预算金额
- 月总支出预算

交互：

1. 用户输入预算金额
2. 点击保存
3. 页面提示保存成功
4. 月度预算总览和月度结算视图使用这些数据重新计算

校验：

- 金额不能为空时按 0 处理
- 金额不能小于 0

## 月度账单大类预算区

### 目标

管理某个月每个账单一级分类的预算。

### 核心内容

1. 月份选择
2. 月度预算总览
3. 月度大类预算表
4. 复制月份预算入口
5. 月度结算视图入口

### 月份选择

用户可以选择当前预算月份。

月份来源：

- 已保存账单月份
- 已创建预算月份

如果当前没有任何月份数据，页面显示空状态并提供新增预算入口。

### 月度预算总览

展示字段：

- 月份
- 月收入
- 月总支出预算
- 当前已支出
- 当前剩余预算
- 月攒钱预算金额
- 预计可攒金额
- 攒钱目标状态

显示规则：

- 当前已支出来自该月已保存账单
- 当月账单未导入时，当前已支出显示 0，并提示“当月账单未导入”
- 预计可攒金额低于月攒钱预算金额时，状态显示未达成

### 月度大类预算表

字段：

1. 大类名称
2. 大类预算金额
3. 已支出金额
4. 剩余预算金额
5. 预算使用率
6. 状态
7. 超支备注
8. 备注
9. 操作

操作：

- 新增大类预算行
- 修改大类名称
- 修改预算金额
- 修改超支备注
- 修改备注
- 删除预算行

删除预算行需要二次确认。

### 大类名称选择

如果当前月份已导入账单，大类名称输入处需要支持从账单一级分类中选择。

交互：

1. 用户点击大类名称输入框
2. 下拉展示该月账单中已有的一级分类
3. 每个选项建议显示分类名称和已支出金额
4. 用户选择后自动填入大类名称
5. 系统自动反写已支出金额、剩余预算金额和状态

用户也可以手工输入大类名称。

### 预算使用率颜色

显示规则：

- 使用率小于 80%：正常显示
- 使用率 80% 到 100%：提醒色
- 使用率超过 100%：金额标红

标红位置：

- 已支出金额
- 剩余预算金额为负数时
- 状态字段

### 复制月份预算

入口：

- 月度大类预算区提供“复制月份预算”按钮

交互：

1. 用户点击复制
2. 选择来源月份
3. 选择目标月份
4. 系统展示将复制的大类数量
5. 如果目标月份已有预算，提示会覆盖目标月份预算
6. 用户确认后复制
7. 复制完成后切换到目标月份

复制结果：

- 复制大类名称、预算金额、备注
- 不复制已支出金额、剩余预算、状态
- 目标月份按目标月份账单重新计算

## 月度结算视图

### 目标

月度结算视图用于月末复盘预算执行情况。

### 核心内容

- 本月总预算是否超支
- 本月月攒钱目标是否达成
- 超支的大类列表
- 剩余预算最多的大类列表
- 全部大类预算执行表

### 全部大类预算执行表字段

1. 大类名称
2. 预算金额
3. 已支出金额
4. 剩余金额
5. 使用率
6. 状态
7. 超支备注

### 交互

- 月份跟随预算管理页当前月份
- 可以返回预算编辑区
- 月度结算视图只展示，不自动修改数据

## 独立购物预算区

### 目标

独立购物预算用于手工管理购物计划，不和账单联动。

### 表格字段

1. 品类
2. 具体项目
3. 计划数量
4. 已购买数量
5. 单位
6. 预算金额
7. 实际购买金额
8. 实际购买小计
9. 剩余预算金额
10. 购买内容
11. 推荐方案
12. 状态
13. 优先级
14. 备注
15. 操作

### 操作

- 新增购物预算行
- 修改任意可编辑字段
- 删除购物预算行

删除购物预算行需要二次确认。

### 合计行

底部合计展示：

- 总预算金额
- 总实际购买金额
- 总剩余预算金额

### 超支显示

如果某行实际购买小计大于预算金额：

- 实际购买金额标红
- 实际购买小计标红

如果品类剩余预算为负数：

- 剩余预算金额标红

## 月度分析页预算联动

### 一级分类表扩展

第二版需要在一级分类表中体现预算状态。

建议新增展示字段：

- 大类预算金额
- 剩余预算金额
- 预算使用率
- 预算状态

如果页面空间不足，可以先把预算信息放在金额点击后的明细弹框中，表格只负责金额标红。

### 一级 + 二级综合表扩展

一级金额字段需要根据预算状态显示：

- 未设置预算：正常显示
- 未超支：正常显示
- 接近预算：提醒色
- 已超支：标红

### 点击一级金额

点击一级金额后，继续打开消费明细弹框。

弹框顶部增加预算信息区：

- 大类名称
- 本月预算金额
- 本月已支出金额
- 剩余预算金额
- 超出预算金额
- 预算使用率
- 超支备注

如果没有设置预算，显示“该大类本月未设置预算”。

原有明细表和底部合计保留。

## 重复月份覆盖确认弹窗

### 触发时机

用户在数据预览页点击保存时，如果本地已经存在相同月份账单，触发覆盖确认弹窗。

### 弹窗内容

用对比表展示：

| 信息 | 已保存账单 | 本次上传账单 |
| --- | --- | --- |
| 月份 | 已保存月份 | 本次识别月份 |
| 文件名 | 已保存文件名 | 本次文件名 |
| 上传时间 | 已保存上传时间 | 当前时间 |
| 原始行数 | 已保存原始行数 | 本次原始行数 |
| 有效支出行数 | 已保存有效支出行数 | 本次有效支出行数 |
| 异常行数 | 已保存异常行数 | 本次异常行数 |
| 月总支出 | 已保存月总支出 | 本次月总支出 |

按钮：

- 覆盖旧账单
- 取消保存

第二版不提供合并按钮。

## 账单管理页扩展

第二版账单管理页建议增加以下字段：

- 原始行数
- 有效支出行数
- 异常行数

已有字段继续保留：

- 月份
- 上传文件名
- 上传时间
- 支出笔数
- 月总支出
- 异常记录数

## 空状态和异常状态

### 预算管理空状态

如果还没有预算：

- 显示“还没有预算数据”
- 提供“新增大类预算”和“新增购物预算”入口

### 当月账单未导入

在月度大类预算区显示：

- “当月账单未导入，已支出金额暂按 0 计算”

### 大类名称未匹配

如果大类名称匹配不到当月账单一级分类：

- 已支出金额显示 0
- 状态显示“未匹配到账单分类”

## 第二版全局交互规则

- 账单大类预算和独立购物预算必须分区展示。
- 账单大类预算可以联动账单。
- 独立购物预算不联动账单。
- 删除预算行必须二次确认。
- 导入本地数据必须二次确认。
- 导入失败不能覆盖当前数据。
- 预算金额和实际金额展示保留 2 位小数。
- 预算使用率展示保留 1 位小数。
