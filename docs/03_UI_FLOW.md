# 03 UI Flow

## 页面设计目标

页面需要让非专业用户也能顺利完成账单上传、数据确认、本地保存历史月份、按月份查看分析结果、点击金额查看明细。

第一版优先保证流程清晰、表格准确，不追求复杂视觉效果。

## 页面列表

1. 首页 / 上传页
2. 账单管理页
3. 数据预览页
4. 月度分析页
5. 图表分析区
6. 一级分类表
7. 二级分类表
8. 一级 + 二级综合表
9. 异常数据列表
10. 消费明细弹框

## 首页 / 上传页

### 目标

让用户上传 iCost 导出的 Excel 或 CSV 文件。

### 核心内容

- 文件上传入口
- 支持文件格式提示
- 简单说明当前版本只做本地解析
- 已保存月份入口
- 上传失败或格式错误提示

### 用户操作

1. 点击上传按钮
2. 选择 Excel 或 CSV 文件
3. 系统进入解析流程
4. 解析成功后跳转到数据预览页

## 账单管理页

### 目标

让用户按月份管理已经上传并保存在本地浏览器中的账单。

### 核心内容

- 已保存月份列表
- 每个月的上传文件名
- 上传时间
- 支出笔数
- 月总支出
- 异常记录数
- 上传新账单入口

### 用户操作

1. 查看已保存月份
2. 点击某个月份进入月度分析页
3. 上传新的月份账单
4. 如果重复上传同一个月份，系统提示是否覆盖旧数据

## 数据预览页

### 目标

让用户确认系统是否正确识别账单字段。

### 核心内容

- 原始数据前若干行预览
- 标准化后的字段预览
- 异常数据列表
- 统计范围说明
- 保存到本地按钮

### 用户操作

1. 查看字段识别结果
2. 查看异常数据
3. 确认统计范围
4. 点击保存，把该月份账单保存到本地
5. 保存成功后进入月度分析页

## 月度分析页

### 目标

展示每个月的收入、支出、结余、结余率。

### 核心字段

- 月份
- 月收入
- 月总支出
- 月结余
- 结余率
- 支出笔数
- 异常记录数
- 备注

### 交互

- 月份可切换
- 点击月总支出，打开该月份全部支出明细弹框
- 非完整月份显示“非完整月，仅参考”

## 图表分析区

### 目标

用图表辅助用户快速理解消费结构，但金额核对仍以表格为准。

### 图表

1. 月度总支出趋势图
2. 一级分类支出占比图
3. 二级分类支出排行图

### 交互

- 月度总支出趋势图展示所有已保存月份
- 一级分类支出占比图跟随当前月份变化
- 二级分类支出排行图跟随当前月份变化
- 图表为空时提示用户先上传账单

## 异常数据列表

### 目标

明确告诉用户哪些记录没有参与统计，以及没有参与统计的原因。

### 字段

1. 原始行号
2. 异常原因
3. 原始日期
4. 原始类型
5. 原始金额
6. 原始一级分类
7. 原始二级分类
8. 原始备注

### 交互

- 数据预览页展示本次上传文件的异常数据
- 月度分析页展示当前月份保存后的异常数据数量
- 异常数据默认不参与支出统计

## 一级分类表

### 字段

1. 一级分类
2. 一级金额
3. 一级占总支出
4. 一级占收入
5. 笔数
6. 备注

### 交互

- 支持按一级金额排序
- 点击一级金额，弹框展示该月份、该一级分类下的所有消费明细

## 二级分类表

### 字段

1. 一级分类
2. 二级分类
3. 二级金额
4. 二级占总支出
5. 二级占收入
6. 笔数
7. 备注

### 交互

- 支持按二级金额排序
- 点击二级金额，弹框展示该月份、该一级分类、该二级分类下的所有消费明细

## 一级 + 二级综合表

### 字段顺序

1. 一级分类
2. 二级分类
3. 一级金额
4. 一级占总支出
5. 二级金额
6. 二级占总支出
7. 二级占一级
8. 一级占收入
9. 二级占收入
10. 二级笔数

### 交互

- 支持按一级金额排序
- 支持按二级金额排序
- 点击一级金额，展示该一级分类明细
- 点击二级金额，展示该二级分类明细

## 消费明细弹框

### 触发方式

- 点击月总支出
- 点击一级金额
- 点击二级金额

### 标题格式

- `2026-05 汽车消费明细`
- `2026-05 汽车-加油消费明细`
- `2026-05 全部支出明细`

### 表格字段

1. 日期
2. 一级分类
3. 二级分类
4. 金额
5. 商户
6. 支付方式
7. 备注

### 底部汇总

- 明细笔数
- 明细合计金额

明细合计金额必须和被点击的金额一致。

## 全局交互规则

- 表格需要支持月份切换
- 表格需要支持按金额排序
- 金额字段需要明显可点击
- 异常数据不能悄悄混入统计
- 已保存月份需要从本地读取
- 同月份重复上传需要二次确认
- 空数据状态需要提示用户重新上传或检查文件
